Что такое API?

API — контракт между клиентом и сервером. Вы запрашиваете данные по URL — сервер отвечает JSON-ом.

GET /api/users/42 
// Нажми кнопку, чтобы увидеть ответ сервера

База данных: таблица users

Данные хранятся как в таблице — строками и столбцами. SQL-запросы их читают и изменяют.

03 / Security

Security: Цифровая крепость

Безопасность — это не только сложные пароли, но и защита от взлома данных, шифрование и бдительность разработчика.

🔐

HTTPS

Шифрует трафик между браузером и сервером. Без него данные видны всем в сети.

💉

XSS

Атака внедрением скриптов. Никогда не вставляй данные пользователя напрямую в HTML.

🛡️

Пароли

Хранятся только как хеши (bcrypt, argon2). Никогда — в открытом виде.

💾

SQL Injection

Используй параметризованные запросы. Никогда не собирай SQL из строк.

⚠️ Демо: innerHTML vs textContent

Введи HTML-теги и посмотри разницу между безопасным и небезопасным выводом

❌ Небезопасно (innerHTML)
✅ Безопасно (textContent)
