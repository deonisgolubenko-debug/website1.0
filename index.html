Что такое API?

API — контракт между клиентом и сервером. Вы запрашиваете данные по URL — сервер отвечает JSON-ом.

GET /api/users/42 
// Нажми кнопку, чтобы увидеть ответ сервера

🔑 Аутентификация: сессии vs JWT

Как сервер узнаёт, кто ты после логина? Два главных подхода:

🍪

Сессии + Cookie

  1. Логин → сервер создаёт сессию в БД
  2. Браузер получает session_id в cookie
  3. Каждый запрос → сервер ищет сессию в БД
  4. Данные хранятся на сервере
✓ Просто отозвать доступ
🎟️

JWT (JSON Web Token)

  1. Логин → сервер подписывает токен
  2. Браузер хранит токен в localStorage
  3. Каждый запрос: Authorization: Bearer <jwt>
  4. Сервер проверяет подпись — без обращения к БД
⚡ Масштабируется лучше

.

⚡ Node.js — Backend на JavaScript

Node.js позволяет писать сервер на том же языке, что и браузер. Вот простой REST API с Express:

// server.js — Node.js + Express
const express = require('express');
const app     = express();
app.use(express.json());

// GET /api/users/:id — получить юзера
app.get('/api/users/:id', (req, res) => {
  const user = db.find(u => u.id === +req.params.id);
  if (!user) return res.status(404).json({ error: 'Not found' });
  res.json(user);
});

// POST /api/users — создать юзера
app.post('/api/users', (req, res) => {
  const { username, email } = req.body;
  const newUser = { id: Date.now(), username, email };
  db.push(newUser);
  res.status(201).json(newUser);   // 201 = Created
});

// DELETE /api/users/:id — удалить
app.delete('/api/users/:id', (req, res) => {
  db = db.filter(u => u.id !== +req.params.id);
  res.status(204).send();          // 204 = No Content
});

app.listen(3000, () => console.log('🚀 Server on :3000'));

03 / Security

Security: Цифровая крепость

Безопасность — это не только сложные пароли, но и защита от взлома данных, шифрование и бдительность разработчика.

🔐

HTTPS

Шифрует трафик между браузером и сервером. Без него данные видны всем в сети.

💉

XSS

Атака внедрением скриптов. Никогда не вставляй данные пользователя напрямую в HTML.

🛡️

Пароли

Хранятся только как хеши (bcrypt, argon2). Никогда — в открытом виде.

💾

SQL Injection

Используй параметризованные запросы. Никогда не собирай SQL из строк.

🌐

CORS

Cross-Origin Resource Sharing. Сервер явно разрешает запросы с нужных доменов через заголовки.

🎭

CSRF

Межсайтовая подделка запроса. Используй CSRF-токены и флаг SameSite для cookie.

⏱️

Rate Limiting

Ограничивай число запросов с одного IP. Защищает от брутфорса и DoS-атак.

📱

2FA / MFA

Двухфакторная аутентификация. Даже при утечке пароля злоумышленник не войдёт без кода.
